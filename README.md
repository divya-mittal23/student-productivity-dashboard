# student-productivity-dashboard
A dashboard to manage student tasks, study time, and productivity.
a web application that helps students organise tasks, manage study time and track productivity.

planned features:
1. add, edit, and delete tasks.
2. mark tasks as completed.
3. add subjects, priorities, and deadlines.
4. use a focus/pomodoro timer.
5. view study progress and task statistics.
6. save data in the browser using localstorage.

technologies:
1. HTML
2. CSS
3. Javascript
4. LocalStorage
